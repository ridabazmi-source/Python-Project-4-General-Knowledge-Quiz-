# General Knowledge Quiz

## Project Overview

The General Knowledge Quiz is a Python-based command-line application developed as part of the DecodeLabs Industrial Training Kit – Python Programming Project 4.

The application asks the user three general knowledge questions, evaluates each response, maintains a score counter, and displays the final score at the end of the quiz.

## Objective

The primary objective of this project is to demonstrate how Python programs can make decisions dynamically based on user input.

The project focuses on:

- If-Else Logic
- Variables
- Control Flow
- State Management
- Input Sanitization
- Dynamic Program Evaluation

## Key Features

- Three general knowledge questions
- Interactive command-line input
- Automatic answer evaluation
- Score tracking
- Correct and incorrect answer feedback
- Input sanitization
- Final score calculation
- Dynamic final result display
